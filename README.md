# 🚀 The Parallel Intercept Choice Matrix
When a screenshot or digital artifact is captured via a long-press directive, the system bypasses automatic system filing and presents a split-path gateway:
1. **The Native Chute:** Standard, rigid device camera-roll storage (Inferior Archive).
2. **The Explorer Vestibule:** Dynamic, expandable, multi-tier directory tree (Superior Custom Vault).

## 🎨 The Dynamic Color Density Horizon
Folders inside the custom vestibule utilize visual weight shifting to communicate internal structural depth on the fly:
* 📁 **Manila Standard (Depth 0):** A freshly minted container with zero internal sub-branches.
* 🔷 **Soft Pastel Blue (Depth 1):** Root folder automatically shifts color to signal an active branching pathway.
* 🔶 **Warm Orange Nexus (Depth 2+):** Visual density indicator warning the eye of a deep, multi-layered structural layout.

## 🔬 Press-and-Hold Hover Mechanics
* **Frictionless Route:** Pressing and holding an image or digital note allows it to hover dynamically into the orbit of the folder matrix.
* **Infinite Malleability:** Directories open, morph, and expand at any passage of time the user commands, keeping naming structures fully adaptable.
